# StudyFlow 产品简介

## 一句话简介

StudyFlow 是把学习计划、专注执行和复盘记录连成一条线的个人学习助手。

## 短简介

StudyFlow 帮你把“想学什么”变成今天能开始的一步：在 Plan 安排任务和截止日期，在 Today 看清今天的重点，进入 Focus 用正计时或番茄钟专注。结束后保存实际投入、完成结果与总结；学习会在今日花园留下成长记录，也可以用 Meditation 做一次短暂恢复，并在 History 回看自己的学习节奏。

## 完整简介

StudyFlow 是一个面向个人学习的计划与执行助手，重点不是帮你堆积更多任务，而是把计划变成真正能开始、能完成、能回看的学习行动。

你可以先在 Plan 中创建月度目标和周里程碑，再把具体任务安排到某一天。任务可以按科目分类，并设置截止日期、重要程度和预计时长；也可以使用四象限看板、任务列表、课表导入或日期建议来整理安排。Today 会集中展示当天的计划、完成情况、实际专注时长和当前进行中的学习。

开始任务后，可以进入 Focus 使用正计时或番茄钟。番茄钟支持单轮模式和多轮模式，过程中可以暂停、继续、休息或结束。完成学习时，用户可以记录这次是完成、部分完成还是未完成，并补充原因、笔记和总结。这样，计划中的预计时间和实际投入不会混在一起，而是形成一条可回看的学习记录。

每次有效学习还会在 Today 的成长花园中留下植物。Meditation 则是独立的恢复入口，支持定时或自由冥想、呼吸引导和结束复盘。History 会保存学习与冥想记录，并支持按日期、分类、任务和结果筛选；如果记录需要修正，也会保留修改原因。每天还可以通过每日复盘回顾进度、当天最大的阻碍，以及明天最重要的一步。

StudyFlow 已实现 PWA。用户可以从 HTTPS 网站安装到 Windows 或 Android，像普通应用一样打开；首次在线加载后，已缓存的页面和本地数据在一定范围内仍可离线使用。新版本发布后，应用会提示用户在合适的时间刷新更新，不需要重新下载一个全新的应用。

## 当前产品边界

StudyFlow 当前是个人学习工具。每位用户的任务、专注记录、冥想记录和复盘内容相互独立。当前版本不包含账号系统、好友协作、云端数据同步或 AI 自动规划。

为了避免更换设备、浏览器或清理网站数据后丢失记录，建议用户定期使用“数据管理”导出备份。

## 当前最核心的产品价值

把学习计划转化为可执行的专注行动，并用真实记录帮助用户持续调整。
