# StudyFlow PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the deployed StudyFlow web app installable on Windows and Android and usable offline without compromising persisted focus data.

**Architecture:** Use `vite-plugin-pwa` to generate a manifest and Workbox service worker at build time. The application shell and immutable build assets are precached; navigation falls back to the cached entry document. A React update prompt exposes waiting-service-worker activation only when the user chooses to refresh.

**Tech Stack:** Vite 7, React 19, TypeScript, vite-plugin-pwa, Workbox, Playwright.

## Global Constraints

- PWA must work over HTTPS in deployment and on localhost for local verification.
- Keep IndexedDB as the sole source of personal data; no cloud sync or background data upload.
- Do not silently reload an active Focus or Meditation session.
- Cache only same-origin application assets; never cache external/private user data.
- Provide Windows Edge/Chrome and Android Chrome installation and offline acceptance instructions.
